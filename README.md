# EasyPaisa - Digital Wallet System (C++)

## About The Project

EasyPaisa is a C++ based digital wallet simulation project developed to demonstrate basic digital payment operations and account management.

The project provides a simple representation of how a digital wallet system works using C++ programming concepts.

## Technologies Used

- C++
- Object-Oriented Programming (OOP)

## Key Features

- Digital Wallet Simulation
- Account Management
- Payment Operations
- Transaction Handling
- Console-Based User Interface

## Concepts Used

- Variables and Data Types
- Conditional Statements
- Loops
- Functions
- Object-Oriented Programming

## How to Run

1. Clone or download this repository.
2. Open the project in Visual Studio Code or any C++ IDE.
3. Compile the C++ source file.
